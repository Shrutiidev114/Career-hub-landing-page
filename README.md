# Career-hub-landing-page
🌿 CareerHub — Your Career. Your Opportunity.

CareerHub is a modern, responsive career and job-opportunity landing page designed to showcase government jobs, exam updates, and study resources through a clean and professional interface.

Built using HTML, CSS, and JavaScript, it features a forest-green and cream color palette, responsive layouts, interactive navigation, smooth scrolling, and subtle animations for a user-friendly experience across desktop, tablet, and mobile devices.

✨ Features
🎨 Modern UI — Clean and professional design.
📱 Responsive Layout — Compatible with desktops, tablets, and smartphones.
🧭 Interactive Navigation — Easy navigation between sections.
🎯 Hero Section — Attractive introduction with call-to-action buttons.
💼 Opportunity Cards — Sections for government jobs, exam updates, and study resources.
📊 Statistics Section — Displays illustrative platform statistics.
⚡ Smooth Scrolling — Smooth navigation between sections.
🪄 Hover Effects & Animations — Engaging visual interactions.
📱 Mobile Navigation — Toggleable menu for smaller screens.
♿ Accessibility — Keyboard focus indicators and reduced-motion support.
🦶 Footer Section — Navigation links and social media placeholders.
🛠️ Technologies Used
HTML5 — Website structure and content.
CSS3 — Styling, responsive layouts, and animations.
JavaScript — Interactive navigation and scrolling functionality.
Google Fonts (Inter) — Modern typography.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository
git clone https://github.com/Shrutiidev114/Career-hub-landing-page.git

2. Open the Project Folder
cd Career-hub-landing-page

3. Run the Website

Open index.html in your browser, or use the Live Server extension in Visual Studio Code.

No build tools or package installations are required.

🎨 Design & Styling

CareerHub uses a forest-green and cream color palette for a clean, professional appearance.

Color	Hex Code	Usage
Forest Green	#276749	Primary buttons and highlights
Dark Green	#173F2B	Dark accents
Cream	#FAF8F2	Main background
White	#FFFFFF	Cards and surfaces
Charcoal	#1F2933	Footer background
Sage Green	#A7C4A0	Accent elements
Light Green	#EDF3E9	Soft backgrounds

Typography: Inter font family from Google Fonts.

Responsive Design: CSS media queries adapt the layout to desktops, tablets, and mobile devices.

⚙️ Current Limitations

CareerHub is currently a frontend landing page. Login, live job listings, exam updates, and backend integration are not yet implemented. Some buttons display placeholder messages.
