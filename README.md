<h1 align="center">🌿Career-hub-landing-page </h1>
 <h4 align="center">CareerHub — Your Career. Your Opportunity.</h4>

CareerHub is a modern, responsive career and job-opportunity landing page designed to showcase government jobs, exam updates, and study resources through a clean and professional interface.

Built using HTML, CSS, and JavaScript, it features a forest-green and cream color palette, responsive layouts, interactive navigation, smooth scrolling, and subtle animations for a user-friendly experience across desktop, tablet, and mobile devices.

## ✨ Features
🎨 Modern UI — Clean and professional design.<br/>
📱 Responsive Layout — Compatible with desktops, tablets, and smartphones.<br/>
🧭 Interactive Navigation — Easy navigation between sections.<br/>
🎯 Hero Section — Attractive introduction with call-to-action buttons.<br/>
💼 Opportunity Cards — Sections for government jobs, exam updates, and study resources.<br/>
📊 Statistics Section — Displays illustrative platform statistics.<br/>
⚡ Smooth Scrolling — Smooth navigation between sections.<br/>
🪄 Hover Effects & Animations — Engaging visual interactions.<br/>
📱 Mobile Navigation — Toggleable menu for smaller screens.<br/>
♿ Accessibility — Keyboard focus indicators and reduced-motion support.<br/>
🦶 Footer Section — Navigation links and social media placeholders.<br/>

## 🚀 Getting Started

### Follow these steps to run the project locally.

1. Clone the Repository
```
git clone https://github.com/Shrutiidev114/Career-hub-landing-page.git
```

3. Open the Project Folder
```
cd Career-hub-landing-page
```

5. Run the Website

Open index.html in your browser, or use the Live Server extension in Visual Studio Code.

No build tools or package installations are required.
